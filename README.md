# FitLog

FitLog is a simple workout library where users can explore workouts, view workout details, add workouts to today's plan, and save workouts for later.

## Technologies

- Next.js 16
- TypeScript
- Tailwind CSS
- Context API
- react-hot-toast

## Key Features

1. Browse workout library with workout cards.
2. View detailed information about each workout.
3. Add workouts to today's plan with a maximum of 5 workouts.
4. Save workouts for later.
5. Manage workouts from My Plan with sorting, metrics, mark as done, and remove options.
6. Data is saved in localStorage after page refresh.
